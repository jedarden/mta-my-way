## Official Documentation

### 1. NixOS Manual (Stable)
- **URL:** https://nixos.org/manual/nixos/stable/
- **Description:** The primary official manual describing how to install, use, and extend NixOS, a Linux distribution based on the purely functional package management system Nix.

### 2. Nix & NixOS Learning Portal
- **URL:** https://nixos.org/learn/
- **Description:** Official NixOS learning portal covering the unique approach to package management and system configuration, focusing on reproducible, declarative, and reliable systems.

### 3. Nixpkgs Reference Manual
- **URL:** https://nixos.org/nixpkgs/manual/
- **Description:** User reference manual for Nixpkgs, the package repository for Nix and NixOS.

### 4. Nix Reference Manual
- **URL:** https://nix.dev/reference/nix-manual.html
- **Description:** Comprehensive Nix package manager reference documentation, available for multiple versions.

### 5. NixOS Download Page
- **URL:** https://nixos.org/download/
- **Description:** Official installation and download information for NixOS.

## Official Wiki & Community Resources

### 6. NixOS Wiki (Official)
- **URL:** https://wiki.nixos.org/wiki/NixOS_Wiki

### 7. NixOS Wiki Resources
- **URL:** https://nixos.wiki/wiki/Resources
- **Description:** Curated collection of guides for broad hands-on understanding, tutorials for specific processes/projects, and cookbooks.

### 8. NixOS Installation Guide (Wiki)
- **URL:** https://nixos.wiki/wiki/NixOS_Installation_Guide
- **Description:** Companion guide to the official manual with known good installation instructions.
